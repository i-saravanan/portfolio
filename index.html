Overview

  • Engineered 15+ REST endpoints handling ticket lifecycle, priority routing, and assignment

FrameSlot — Studio
Booking Platform

Overview

A cloud-deployed booking system for studio time slots. Enables secure reservation pipelines, JWT-secured customer and admin workflows, and real-time confirmations via automated email services. Deployed in a production-ready environment on AWS EC2 and RDS.

Key Features

  • JWT-secured REST endpoints for secure client transactions and sign-ins
  • Real-time slot reservation pipeline, preventing double-bookings
  • Automated booking confirmations dispatched instantly using JavaMailSender
  • Scoped access boundaries isolating Admin configurations from Customer reserves
  • AWS cloud deployment using EC2 hosting and AWS RDS MySQL database

Engineering Decisions

  • Used JavaMailSender to keep clients updated asynchronously without slowing down thread returns
  • Decoupled hosting into AWS EC2 compute and AWS RDS databases for database redundancy
  • Used stateless JWT authentication headers to simplify micro-service scoping

Challenges Solved

  • Eliminating double-booking reservation conflicts—handled by using SQL database row locks during selection
  • Resolving network communication bottlenecks between EC2 and RDS—solved with configured VPC security groups
