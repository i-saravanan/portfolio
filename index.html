Role-Based Ticket
Management System

Overview

A production-grade helpdesk platform with three distinct role tiers — Admin, Manager, and User. Each role has precisely scoped access to ticket operations, enforced at the API layer via Spring Security. The system handles the full lifecycle of support tickets from creation through resolution.

Key Features

  • Role-based access control (Admin / Manager / User) with Spring Security filter chain
  • Ticket creation, assignment, reassignment, and escalation workflows
  • Priority levels and SLA-aware status tracking via Enum state machine
  • RESTful APIs following standard HTTP semantics with DTO decoupling
  • Normalized MySQL schema with foreign key integrity and lazy loading

Engineering Decisions

  • Chose Spring Security filter chain over manual auth for maintainability
  • Used DTO pattern to decouple API contracts from entity models
  • Separated service layer from controller to enable future unit testing
  • Used Enum types for ticket status to prevent invalid state transitions

Challenges Solved

  • Circular dependency between User and Role entities — resolved with lazy loading
  • Cascading update conflicts on ticket reassignment — handled with explicit merge strategies
  • Scope isolation per role without duplicating endpoints — solved via method-level security

Employment Leave
Management System

Overview

A full-featured enterprise leave management backend that models real HR workflows. Employees request leave, managers approve or reject, and HR maintains balance records. Every action is auditable and role-scoped.

Key Features

  • Multi-role system: HR Admin, Manager, Employee
  • Leave request creation, approval, rejection, and cancellation
  • Leave balance tracking with automatic deduction on approval
  • Leave type configuration (Annual, Sick, Casual)
  • Full CRUD with Hibernate ORM entity mapping and state machine pattern

Engineering Decisions

  • Used Hibernate directly (no Spring Data JPA) for fine-grained ORM control
  • Designed bidirectional relationships between Employee and LeaveRequest entities
  • Implemented state machine pattern for leave status transitions
  • Global exception handler via @ControllerAdvice for consistent error responses

Smart Agriculture
REST Service

Overview

A Spring Boot REST API that integrates with a machine learning classification model to recommend the most suitable crop based on soil and climate parameters. It features request validation, prediction caching, and database logging of all inquiries.

Key Features

  • REST endpoints for crop recommendation requests and historical query retrieval
  • Integration with external ML services via Spring RestTemplate/WebClient
  • Validation of soil and climate parameters before processing
  • MySQL persistence for logging input metrics and prediction history
  • Role-based access control for administrative query analytics

Engineering Decisions

  • Used Spring RestTemplate to communicate with the REST-based Machine Learning microservice to keep backend and ML concerns separated
  • Stored prediction results in MySQL for auditing and analytical reporting
  • Implemented validation constraints on request parameters to prevent sending malformed data to the model
