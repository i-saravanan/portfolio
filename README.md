# Saravanan Iyappan Portfolio

Immersive futuristic portfolio for a Java Backend Developer, built with Next.js, Tailwind CSS, Framer Motion, Lucide React, Three.js, and React Three Fiber.

## Run Locally

```powershell
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Personalize Next

- Replace `your-email@example.com` in `app/page.tsx`.
- Replace the placeholder GitHub and LinkedIn URLs in `app/page.tsx`.
- Add project GitHub/demo links when available.
- Add formal education, certifications, resume, and work experience when ready.
