# Saravanan Iyappan Portfolio

Immersive futuristic portfolio for a Java Backend Developer, built with Next.js, Tailwind CSS, Framer Motion, Lucide React, Three.js, and React Three Fiber.

## Run Locally

```powershell
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```
